# MKVToolNix Batch Remuxer

**Быстрая пакетная сборка аниме-сериалов в MKV** — HTA-приложение для Windows, которое генерирует готовый скрипт `remux.cmd` для MKVToolNix. Принцип «одна серия — один файл»: вы указываете, где лежат видео, аудио, субтитры и шрифты, а программа по совпадению имён создаёт скрипт, который собирает каждую серию в отдельный MKV — без ручного ввода команд.

Программа **не перекладывает файлы и не трогает исходники** — она только читает указанные папки, находит файлы с совпадающими именами (до первой скобки) и генерирует `remux.cmd`. Скрипт уже сам вызывает `mkvmerge` и собирает каждую серию в один MKV в папке вывода: видео + внешнее аудио + субтитры «Надписи» и полные + шрифты.

## ✨ Возможности

- 📂 **Группировка по имени** — файлы сопоставляются по общей части имени (до первой скобки `(` или точки)
- 🎬 **Видео + аудио + субтитры + шрифты** — все дорожки собираются в один MKV
- 🏷️ **Умные имена дорожек** — суффикс из имени аудио автоматически попадает в название дорожки (`Rus [Beloved]`)
- 💬 **Два типа субтитров** — «Надписи» (короткие) и полные русские с настраиваемым именем дорожки
- 🔤 **Шрифты** — ttf/otf/woff/woff2 прикрепляются ко всем файлам
- 🔁 **Галочка «Оставить аудио из видео»** — сохраняет оригинальную дорожку как запасную (без флага default)
- 💾 **Сохранение сессии** — все пути запоминаются в реестре
- 🐞 **Подробные логи** — `mkv_remuxer_debug.log` и `remux_log.txt` для диагностики
- ⚡ **Пакетная обработка** — один запуск `remux.cmd` обрабатывает все найденные серии

## 🚀 Быстрый старт

1. **Разложите файлы по папкам** (или укажите, где они уже лежат):
   ```
   video/   — Killing Bites 01 (BDRip 1920x1080 x264 FLAC).mkv
   audio/   — Killing Bites 01 (BDRip 1920x1080 x264 FLAC).mka
   subs/    — Killing Bites 01 (BDRip 1920x1080 x264 FLAC).ass
   fonts/   — шрифты (опционально)
   output/  — сюда попадут готовые MKV
   ```

2. **Запустите `MKVToolNix Batch Remuxer v1.x.xx`**, укажите папки через «Обзор».

3. Нажмите **«Проверить файлы»** — убедитесь, что все группы найдены.

4. Нажмите **«Создать CMD»** → в папке вывода появится `remux.cmd`.

5. **Запустите `remux.cmd`** двойным кликом. Готово! 🎉

## 📋 Требования

- **Windows** (HTA работает через `mshta.exe`, встроен в систему)
- **MKVToolNix** — [скачать](https://mkvtoolnix.download/) (нужен `mkvmerge.exe`, обычно `C:\Program Files\MKVToolNix\mkvmerge.exe`)
- Никаких установок Python/Node — всё на VBScript + JScript

## ⚙️ Как работает группировка

Ключ совпадения — часть имени **до первой скобки `(`** (или до первой точки, если скобок нет). Всё, что идёт после ключа в имени аудио, становится **суффиксом** и добавляется к имени дорожки:

```
video: [ReinForce] Kaifuku Jutsushi 01 (BDRip 1920x1080).mkv
audio: [ReinForce] Kaifuku Jutsushi 01 (BDRip 1920x1080).[Beloved].mka
                                              ^^^^^^^^^
→ имя дорожки: Rus [Beloved]
```

Имена дорожек по умолчанию:

| Дорожка | Имя |
|---|---|
| Аудио | `Rus` или `Rus [суффикс]` |
| Надписи | `Надписи` |
| Полные субтитры | из поля «Имя дорожки» (по умолчанию `Rus`) |

## 🩺 Диагностика

В папке вывода создаются логи:
- **`remux_log.txt`** — статус обработки каждого файла (`[OK]` / `[ERROR]`)
- **`mkv_remuxer_debug.log`** — все сгенерированные команды `mkvmerge`

Если что-то пошло не так — откройте второй лог: обычно проблема видна сразу.

---

## ❓ Частые проблемы

| Проблема | Решение |
|---|---|
| «Группы не найдены» | Проверьте, что имена видео и аудио совпадают до первой скобки |
| «mkvmerge не найден» | Укажите верный путь к `mkvmerge.exe` |
| Ошибки при запуске CMD | Откройте `mkv_remuxer_debug.log` и проверьте сгенерированные команды |
